# Working on the example

This is an independent synthetic support application, not a live customer integration.
Read README.md for the runnable sequence and expected report semantics.

Run `uv run pytest -q` for application checks. The native SDK always uses the local
MockTransport in fixture_provider.py. Do not replace it with a network transport,
read ambient provider keys, or enable paid inference for this walkthrough.

Cutback observation is optional. Keep content capture disabled, label all traffic
as simulation, and retain unknown usage/cost as unknown. Never convert fixture
labels, token counts or modeled subtotals into real quality or savings claims.
Credentials and source maps belong in ignored `.cutback/`, never source, terminal
output, screenshots, commits or issue bodies. Use separate scoped ingest/viewer
keys. Respect an uncertain setup phase; do not erase it to repeat key issuance.

Preserve the original ticket-routing checks when evaluating a proposed model or
output-cap change. Run them against both trees and present an exact diff. No
deployment, paid request or public release is authorized by this file.

Use only independent synthetic inputs. Private application identities, source and
integration details must stay outside this repository and its history/archives.
